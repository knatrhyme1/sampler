SMPLR Export

Закладка, которая забирает WAV-экспорт паттерна из Serial Monitor в Wokwi и сохраняет его файлом.

SMPLR Export

Установка, один раз

  1. Покажи панель закладок: Ctrl+Shift+B.
  2. Перетащи оранжевую кнопку «SMPLR Export» на панель закладок.

Экспорт

  1. Открой проект в Wokwi, запусти симуляцию, нарисуй паттерн в разделе 1.
  2. Нажми закладку «SMPLR Export» — в правом нижнем углу появится плашка «Жду экспорт».
  3. На устройстве с главного экрана: MODE → пункт EXPORT (PAD2 вниз, PAD3 открыть) → PAD5. Из секвенсора сначала выйди на главный экран (PAD5).
  4. Когда полоса дойдёт до конца, браузер скачает smplr-pattern-120bpm.wav.

Файл проверяется по CRC32: если хоть одна строка потерялась, плашка скажет об этом, а файл не скачается. Закладку достаточно нажать один раз за сессию — она ловит все следующие экспорты.
