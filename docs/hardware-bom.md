# Планируемое железо

Список компонентов под реальную (не Wokwi) сборку сэмплера. Статус —
что уже куплено, что нужно докупить, что заменено по ходу подбора.

## Куплено

| Компонент | Модель/чип | Зачем |
|---|---|---|
| Контроллер | ESP32-S3 Dev Board N16R8 (Type-C, 16 МБ флеш / 8 МБ PSRAM) | основная плата; на борту два порта USB-C — один UART/прошивка, второй native USB (для MPK) |
| Аудиокодек | WM8960 | одновременный вход/выход по I2S, встроенный mic-вход, headphone-выход 3.5 мм, I2C-управление |
| Экран | ILI9341 2.8", SPI, **с тачскрином** | вывод интерфейса; тач не входит в текущую архитектуру (весь ввод — с MPK), но берём с запасом под будущий touch-режим управления |
| Хранилище | microSD-модуль, SPI | сэмплы, экспорт WAV |
| Операционный усилитель | NE5532 (сдвоенный) | буфер/согласование уровня line-in перед ADC кодека |
| Аккумулятор | Li-Po 3.7В 3000 мА·ч, разъём PH2.0 | автономное питание |
| Зарядное устройство | TP4056 1A (Type-C или Micro-USB) | заряд аккумулятора с защитой от переразряда/КЗ |

## Нужно докупить / заменить

| Компонент | Статус | Комментарий |
|---|---|---|
| **Boost-модуль до 5В** | не куплен, **критично** | TP4056 даёт на выходе только напряжение батареи (3.6–4.2В), а не 5В. MPK mini как USB-устройство требует 5В по VBUS. Нужен отдельный повышающий модуль либо готовая плата «заряд + boost 5В» вместо голого TP4056. Без этого узла USB-хост для MPK не заработает |
| USB-A разъём, панельный (chassis mount, 4-pin) | не куплен | порт под MPK mini прямо в корпусе, провода на native USB пины (GPIO19/GPIO20) платы ESP32-S3, а не через переходник |
| Тумблер питания | заменить | куплен E-TEN1021 (15А/250В, 54 мм) — рассчитан на сетевое напряжение, избыточно крупный для батарейного DC-узла. Взять компактный панельный SPDT-тумблер под низковольтную DC-цепь |
| Джек 3.5 мм, switched | не куплен | line-in №1 |
| Джек 6.3 мм TRS, switched | не куплен | line-in №2 |
| RCA-гнёзда (тюльпан), пара | не куплены | line-in №3 |
| Тактовые кнопки 6×6 мм, 2–3 шт | не куплены | Play/Stop/Rec — у MPK mini нет своих транспортных кнопок |

## Отклонено при подборе

- **MH-M28 (Bluetooth-приёмник)** — не подходит: только приём аудио по BT и аналоговый выход, нет line-in для сэмплирования, нет I2S для связи с ESP32.
- **USB 3.0 → Type-C OTG-переходник** — куплен по инерции, но противоречит решению делать полноценный порт в корпусе. Оставить как временное решение для тестов на столе; для финальной сборки — панельный USB-A разъём (см. таблицу выше).
