# Снимки экранов

Каталог для снимков экрана устройства из симуляции. Файлов пока нет:
ниже — что именно нужно снять и как.

## Как снять

1. Открыть <https://wokwi.com/projects/475304919575815169> и запустить
   симуляцию. Вкладка должна быть видимой и активной: в фоновой вкладке
   браузер тормозит симуляцию примерно до 1 % скорости.
2. Дождаться нужного экрана по сценарию из таблицы.
3. Снять область дисплея ILI9341 и сохранить под указанным именем.
4. Дисплей 320 × 240; кадрировать по краю экрана, без корпуса модуля.

## Что нужно снять

| Файл | Экран | Как получить |
| --- | --- | --- |
| `off.png` | выключено | состояние сразу после старта симуляции |
| `boot.png` | загрузка | удержать `POWER`, снять во время анимации |
| `home.png` | главный | после загрузки; поставить несколько ударов, чтобы был виден индикатор OUT |
| `sequencer.png` | раздел 1 | PAD5 на разделе 1, набрать рисунок на всех четырёх каналах |
| `mixer.png` | раздел 2 | PAD5 на разделе 2, развести громкости полос |
| `piano-roll.png` | раздел 3 | PAD5 на разделе 3, поставить несколько нот |
| `arrangement.png` | раздел 4 | PAD5 на разделе 4 |
| `menu.png` | список меню | `MODE` |
| `tempo.png` | TEMPO | `MODE` → PAD5 на TEMPO |
| `input.png` | INPUT | `MODE` → PAD5 на INPUT, покрутить K1 |
| `system.png` | SYSTEM | `MODE` → PAD5 на SYSTEM |
| `export.png` | EXPORT | `MODE` → PAD5 на EXPORT, снять во время передачи |

Снимки должны быть сделаны с текущей прошивки: имена каналов на них —
KICK, CLSD HAT, OPEN HAT, CRASH.
