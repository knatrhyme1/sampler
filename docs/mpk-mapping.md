# Раскладка MPK mini

Документ фиксирует **снятое поведение**, а не общую спецификацию Akai MPK mini.

## Замер

- Контроллер: Akai MPK mini mk3
- Пресет: кастомный, переназначенный под FL Studio
- Дата замера: 2026-09-16
- Инструмент: [`tools/midi_logger.py`](../tools/midi_logger.py)

Заводской пресет и другие контроллеры не проверялись.

На устройстве MPK будет подключаться к native USB платы (GPIO19/GPIO20) через панельный разъём USB-A в корпусе. Питание 5 В на VBUS от батареи требует повышающего модуля — см. [`hardware-bom.md`](hardware-bom.md). Для тестов на столе допустим OTG-переходник.

## Ноты и пэды

| Элемент | Канал | MIDI | Что наблюдается |
| --- | ---: | --- | --- |
| Клавиатура | 1 | ноты 48–72 | C3–C5, сила нажатия динамическая |
| Пэды, банк A | 10 | ноты 45, 47, 48, 50, 52, 53, 55, 57 | текущий пресет ударных и навигации |
| Пэды, банк B | 10 | ноты 59, 60, 62, 64, 65, 67, 69, 71 | альтернативный банк пэдов |
| K1–K8 | 1 | CC 70–77 | абсолютные 0–127 |
| Джойстик X | 1 | Pitch Bend | возвращается в центр |
| Джойстик Y | 1 | CC 1 | возвращается в центр |

Ноты пэдов перечислены по номерам на корпусе: PAD1–4 — нижний ряд слева направо, PAD5–8 — верхний. Прошивка берёт эту таблицу из `firmware/mpk_mapping.h`.

## Важное поведение контроллера

Часть физических органов управления в снятом пресете не отправляет отдельного MIDI-сообщения — они меняют поведение самого контроллера.

Замеченные примеры:

- Octave вверх/вниз;
- Full Level;
- Note Repeat;
- Arp On/Off;
- Tap Tempo;
- Bank A/B;
- органы CC / Program Change / Program Select.

Отсутствие MIDI-сообщения не значит, что орган управления ничего не делает.

## Крутилки

Снятый пресет отправляет абсолютные значения CC.

Прошивка превращает поток абсолютных значений в приращения и только потом применяет их к параметрам. Так параметр не прыгает при смене страницы интерфейса.

Это программный обход, а не доказательство того, что контроллер работает как настоящий относительный энкодер ([known-issues, п. 11](known-issues.md#11-абсолютный-режим-крутилок-mpk-упирается-в-края-диапазона)).

## Повторный замер

```bash
pip install -r tools/requirements.txt
python tools/midi_logger.py
```

Замеряйте по одному органу управления и записывайте канал, тип сообщения, номер и значение.

Новый пресет или изменённая конфигурация контроллера делают текущую раскладку недействительной до повторного замера.
