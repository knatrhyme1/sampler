# ТЗ: техническая переделка исходника логотипа под прошивку

Не редизайн — тот же стиль/цвета/композиция, но источник должен
имплементироваться примитивами Adafruit_GFX без разрывов кадра в Wokwi.

## Проблема с текущим исходником

`smplr-logo.png` — растр с мелкой хатч-текстурой (диагональная штриховка
внутри букв). При переводе в 1-бит и отрисовке через
`drawFastHLine()` (по одному вызову на каждый горизонтальный "пробег"
закрашенных пикселей) получаются **тысячи мелких SPI-команд на кадр**.
В симуляторе Wokwi это рвёт кадр (tearing) — логотип отображается
раздробленным и переставленным местами. Подробности —
`docs/known-issues.md`, раздел 1.

## Требование к новому исходнику логотипа

**Сплошная заливка, без текстуры внутри букв.** Буквы "SMPLR" — один
сплошной цвет (кремовый `#F5EFE1`), без хатча, без градиента, без шума
внутри контура. Контур/аутлайн (если он часть стиля) — тоже сплошной, не
пунктирный.

Почему это чинит проблему: сплошная заливка на строку растра даёт
**1–3 горизонтальных пробега на строку** вместо десятков — на 2–3 порядка
меньше SPI-транзакций на кадр.

## Что оставить как есть

- Композиция, наклон, толщина букв, общий силуэт слова — не менять.
- Хроматическая аберрация/глитч-копии, цветные конфетти-пиксели, прогресс-бар,
  статус-текст, футер — это уже реализовано процедурно в прошивке
  (`firmware/ui_screens.cpp`), исходника не касается.
- Разрешение/пропорции исходного PNG — не важны, конвертер
  (`tools/png_to_bitmap.py`) сам ресемплит под 320×140.

## Формат сдачи

PNG с альфа-каналом, буквы — один сплошной непрозрачный цвет, фон —
прозрачный. Ничего конвертировать не нужно — просто замените
`smplr-logo.png` на новую версию, дальше в прошивку заводим тем же
инструментом (`tools/png_to_bitmap.py`).
