# Список компонентов

Инженерный список под физическую сборку. Сейчас идёт подбор конкретных
позиций: по цене, характеристикам и совместимости с прошивкой и планами.

**Ничего из списка ещё не заказано.** Ссылка на магазин или выбранная
модель не переводят компонент на следующую стадию.

```text
Candidate → Selected → Ordered → Arrived → Bench-tested → Integrated
```

| Стадия | Что она означает |
| --- | --- |
| Candidate | роль понятна, конкретная модель ещё не выбрана |
| Selected | выбрана конкретная модель с проверенной документацией |
| Ordered | заказана |
| Arrived | пришла и опознана |
| Bench-tested | проверена отдельно, вне устройства |
| Integrated | работает в составе SMPLR |

## Что нужно проверить до заказа

1. **Потребление.** Ток MPK по USB, ток платы, дисплея и кодека. Без этих
   цифр нельзя выбрать ни повышающий модуль, ни ёмкость аккумулятора.
2. **Схема линейного входа.** От неё зависит, годится ли NE5532 или нужен
   операционный усилитель с однополярным питанием и rail-to-rail выходом.
3. **Вариант платы ESP32-S3.** Распиновка, разъёмы, доступ к native USB и
   реальные свободные выводы.
4. **Конкретный модуль WM8960.** Питание, MCLK, подтяжки, разводка входов.
5. **Совмещение заряда и работы.** Можно ли пользоваться устройством, пока
   идёт зарядка.

## Отклонено при подборе

- **MH-M28 (приёмник Bluetooth)** — только приём звука и аналоговый выход:
  нет линейного входа для сэмплирования и нет I2S.
- **Переходник USB 3.0 → Type-C OTG** — противоречит решению делать порт в
  корпусе. Допустим только как временное решение для проверок на столе.
- **Тумблер E-TEN1021 (15 А / 250 В)** — рассчитан на сетевое напряжение и
  слишком крупный для батарейной цепи.
