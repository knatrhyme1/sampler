# Карта интерфейса

Справочник по экранам: куда ведёт какой контрол. Пошаговое объяснение для
пользователя — в [`user-manual.md`](user-manual.md).

## Откуда берутся контролы

**Внешний MIDI-контроллер — Akai MPK mini mk3.** Одно USB-устройство.
Клавиатура, пэды, крутилки, джойстик и прочие его органы управления
отправляют MIDI; SMPLR разбирает поток.

| Обозначение | Что это | Роль в интерфейсе |
| --- | --- | --- |
| PAD1–PAD8 | восемь пэдов контроллера | навигация, подтверждение, действия экрана |
| K1–K8 | восемь крутилок контроллера | параметры текущего экрана |
| C3–D#3 | четыре нижние клавиши | прослушать ваншот канала |
| джойстик | орган управления контроллера | в интерфейсе не используется |

**Локальные контролы SMPLR.** Кнопки самого устройства.

| Контрол | Роль | Статус |
| --- | --- | --- |
| `POWER` | включение и выключение | Provisional |
| `PLAY/STOP` | транспорт | Provisional |
| `MODE` | меню | Provisional |

Пэды в роли навигации — текущий UX-эксперимент. Окончательный набор
физических кнопок SMPLR не утверждён
([decision-log, D8](decision-log.md)).

## Общие правила

| Контрол | Действие на любом экране |
| --- | --- |
| PAD6 / PAD2 | курсор вверх / вниз |
| PAD1 / PAD3 | курсор влево / вправо, назад / вперёд по уровню |
| PAD5 | подтвердить, нажать элемент под курсором |
| PAD7 | назад |
| PAD4 | метроном включить или выключить |
| `MODE` | меню и обратно туда, откуда пришли |
| `PLAY/STOP` | запустить или остановить паттерн |

Проигрывание не прерывается при переходах между экранами.

## Экраны

### OFF

```text
Назначение  устройство выключено
Вход        удержание POWER на включённом устройстве
Контролы    POWER — удержать 0,6 с, на экране идёт полоса
Выход       по завершении удержания начинается загрузка
Примечания  звук и интерфейс не работают
```

### BOOT

```text
Назначение  загрузка, около 3 секунд
Вход        автоматически после включения
Контролы    нет — процесс нельзя прервать
Выход       автоматически на главный экран
```

### HOME — главный экран

```text
Назначение  темп, метроном, выбор раздела проекта, индикатор выхода
Вход        после загрузки; PAD7 из любого раздела
Контролы    PAD6/PAD2   между верхней строкой (BPM, MET) и рядом разделов
            PAD1/PAD3   влево/вправо внутри строки
            PAD5        на MET — метроном; на разделе — выбрать,
                        повторно на выбранном — открыть
            K1          темп
            MODE        меню
Выход       PAD5 на выбранном разделе, MODE, удержание POWER
Примечания  разделы: 1 SEQUENCER, 2 MIXER, 3 PIANO ROLL, 4 ARRANGEMENT
```

### Раздел 1 — SEQUENCER

```text
Назначение  сетка 4 канала x 16 шагов, один такт шестнадцатыми
Вход        PAD5 на выбранном разделе 1
Контролы    PAD6/PAD2   канал вверх/вниз
            PAD1/PAD3   шаг влево/вправо, по кругу
            PAD5        поставить или убрать удар
            PAD8        очистить канал; второе нажатие подтверждает
            K1          темп
            C3–D#3      прослушать ваншот канала и перевести на него курсор
Выход       PAD7
Примечания  каналы: KICK, CLSD HAT, OPEN HAT, CRASH
```

### Раздел 2 — MIXER

```text
Назначение  громкость каналов, метронома и мастера
Вход        PAD5 на выбранном разделе 2
Контролы    PAD1/PAD3   выбор полосы
            PAD6/PAD2   громкость выбранной полосы, шаг 5
            PAD5        mute
            K1–K6       громкость своей полосы напрямую
            C3–D#3      прослушать канал и выбрать его полосу
Выход       PAD7
Примечания  шесть полос: четыре канала, метроном, мастер; 0–100
```

### Раздел 3 — PIANO ROLL

```text
Назначение  превью: ноты хранятся и видны, но пока не звучат
Вход        PAD5 на выбранном разделе 3
Контролы    PAD6/PAD2   высота вверх/вниз, окно едет за курсором
            PAD1/PAD3   шаг влево/вправо, по кругу
            PAD5        поставить или убрать ноту
Выход       PAD7
Примечания  две октавы C3–C5, на экране одна
```

### Раздел 4 — ARRANGEMENT

```text
Назначение  превью: текущий паттерн на шкале в 16 тактов
Вход        PAD5 на выбранном разделе 4
Контролы    PAD6/PAD2   строка
            PAD1/PAD3   такт
Выход       PAD7
Примечания  редактирования песни ещё нет
```

### MENU

```text
Назначение  список страниц настроек
Вход        MODE с любого экрана
Контролы    PAD6/PAD2   выбор пункта
            PAD5/PAD3   открыть
Выход       PAD7, PAD1 или MODE — туда, откуда пришли
Примечания  пункты: TRACK, TEMPO, INPUT, SYSTEM, EXPORT
```

### MENU → TRACK

```text
Назначение  заготовка: содержимого ещё нет
Вход        MENU, PAD5 на TRACK
Контролы    нет
Выход       PAD7 или PAD1
```

### MENU → TEMPO

```text
Назначение  темп и метроном
Вход        MENU, PAD5 на TEMPO
Контролы    PAD6/PAD2   строка: BPM или MET
            PAD1/PAD3   на BPM — минус/плюс 1; на MET — переключить
            PAD5        метроном
            K1          темп
Выход       PAD7
Примечания  диапазон 40–240, меняется и во время проигрывания
```

### MENU → INPUT

```text
Назначение  скорость крутилок и проверка входящих событий
Вход        MENU, PAD5 на INPUT
Контролы    PAD1/PAD3   скорость: 1, 2 или 4 единицы за щелчок
            K1–K8       показать последнее событие крутилки
Выход       PAD7
```

### MENU → SYSTEM

```text
Назначение  флеш, PSRAM, свободная память, время работы
Вход        MENU, PAD5 на SYSTEM
Контролы    нет
Выход       PAD7 или PAD1
```

### MENU → EXPORT

```text
Назначение  свести текущий паттерн в WAV
Вход        MENU, PAD5 на EXPORT
Контролы    PAD5    начать; проигрывание при этом останавливается
            PAD7    отменить передачу или выйти
Выход       PAD7
Примечания  44,1 кГц, 16 бит, моно; пустой паттерн не экспортируется.
            Страница показывает прошлый результат до следующего экспорта
            ([known-issues, п. 13](known-issues.md#13-результат-экспорта-ничем-не-обесценивается))
```
