# SMPLR — DAWless-сэмплер и секвенсор

SMPLR — автономный аппаратный сэмплер-секвенсор на ESP32-S3: сэмплирует,
секвенирует и обрабатывает звук без компьютера. Управление — с внешнего
USB-MIDI контроллера Akai MPK mini.

```text
Текущая веха       PoC → запуск на железе
Физический прототип ещё не собран
Железо             идёт подбор компонентов, ничего не заказано
Версия             0.0.1.1, ветка current-state
```

Поведение проверяется в симуляции Wokwi и регрессионными тестами на ПК.
Что именно доказано — в [`docs/product-status.md`](docs/product-status.md).

## Что уже работает

В симуляции:

- интерфейс с четырьмя разделами проекта;
- степ-секвенсор: 4 канала × 16 шагов, один такт шестнадцатыми
  (KICK, CLSD HAT, OPEN HAT, CRASH);
- транспорт со сменой темпа на ходу и метрономом;
- микшер: громкость каналов, метронома и мастера;
- прослушивание встроенных ваншотов с клавиатуры;
- экспорт паттерна в WAV — 44,1 кГц, 16 бит, моно;
- звук считается в отдельной задаче, а время транспорта — в звуковых
  сэмплах, независимо от отрисовки экрана.

Piano roll и аранжировка — сознательно превью: ноты хранятся и видны, но
пока не звучат, а песню редактировать нельзя.

Устройство пока не принимает MIDI с настоящего контроллера, не выводит
звук через кодек, не загружает свои сэмплы и не сохраняет проект. Полный
список ограничений — в [`docs/known-issues.md`](docs/known-issues.md).

### Забрать экспортированный WAV

Wokwi не отдаёт файлы из симуляции, поэтому прошивка печатает WAV в Serial
Monitor текстом, а забирает его закладка браузера.

1. Откройте [`tools/export_bookmarklet.html`](tools/export_bookmarklet.html)
   (на Windows — двойным щелчком по `tools/export_bookmarklet.bat`).
2. Перетащите кнопку «SMPLR Export» на панель закладок. Если закладка
   стояла раньше — перетащите заново: 20.09.2026 формат передачи изменился.
3. На странице Wokwi нажмите закладку **до** старта экспорта, затем
   запустите его на устройстве: `MODE` → `EXPORT` → `PAD5`.

Прогресс виден в заголовке вкладки, файл падает в «Загрузки».
Целостность проверяется по CRC32: повреждённый файл не сохраняется.

Запасной путь, если файл не скачался, а текст в мониторе остался:
сохранить его в `.txt` и перетащить на `tools/wav_from_serial.bat`.

## Как устроено

```text
Akai MPK mini mk3  →  USB-MIDI  →  ESP32-S3  →  UI / секвенсор / звук
```

Контроллер — одно внешнее USB-MIDI устройство. Его клавиши, пэды, крутилки
и джойстик формируют MIDI внутри самого контроллера и не являются
отдельными входами SMPLR.

Внутри прошивки:

```text
InputSource → приложение → Transport → AudioEngine → AudioSource → выход
                              ↑
                        StepSequencer
```

- **`InputSource`** прячет железо ввода: сегодня это симуляция, завтра —
  USB-MIDI.
- **`StepSequencer`** хранит данные паттерна и ничем больше не владеет.
- **`Transport`** владеет музыкальным временем, считает его в звуковых
  сэмплах и запускает голоса.
- **`AudioEngine`** микширует и ограничивает, не зная, куда уходит звук.
- **`PatternExporter`** сводит паттерн офлайн своим экземпляром движка.

Подробно — в [`docs/architecture.md`](docs/architecture.md); железо — в
[`docs/hardware/architecture.md`](docs/hardware/architecture.md).

## Железо

Компоненты **ещё не заказаны**: идёт подбор конкретных моделей по цене,
характеристикам и совместимости. Список со стадиями закупки — в
[`docs/hardware/bom.md`](docs/hardware/bom.md).

Основные узлы в проработке: плата ESP32-S3 с native USB, кодек WM8960,
дисплей ILI9341 по SPI, microSD, буфер линейного входа, питание от Li-Po с
зарядом и повышением до 5 В для USB-хоста.

Незакрытые вопросы, без которых нельзя заказывать: потребление, схема
линейного входа, конкретный вариант платы и конкретный модуль кодека.

Порядок проверки собранного устройства — в
[`docs/hardware/bring-up.md`](docs/hardware/bring-up.md).
