# DAWless сэмплер-секвенсор на ESP32-S3

Автономная коробка для живой игры в духе OP-1: сэмплер, многодорожечный
лупер-секвенсор и цепочка эффектов. Управление с Akai MPK mini, без
компьютера. Пет-проект для портфолио.

## Статус

Сейчас в разработке **Proof of Concept** — минимальный набор функций,
подтверждающий, что идея работает:

- 4 фиксированные дорожки, сетка 16 шагов, длина лупа 1 такт
- Ручная установка темпа, метроном, старт/стоп
- Живая запись нот с MPK mini с привязкой к шагу
- Один WAV-сэмпл на дорожку, воспроизведение с разной высотой по клавишам
- Без эффектов, без автоматизации — чистый звук

Полный список задуманных возможностей и порядок разработки — в
[`docs/backlog.md`](docs/backlog.md). Раскладка Akai MPK mini (клавиши, пэды,
крутилки, джойстик) — в [`docs/mpk-mapping.md`](docs/mpk-mapping.md).

## Железо

- ESP32-S3, вариант N16R8 (16 МБ флеш, 8 МБ PSRAM)
- Аудиокодек с одновременным входом и выходом (WM8960 или ES8388)
- microSD
- Цветной экран (ST7789)
- Akai MPK mini по USB

## Структура репозитория

- `firmware/` — код для ESP32-S3 (Arduino), симулируется в
  [Wokwi](https://wokwi.com)
- `sound-engine/` — звуковой движок, отдельно собирается на компьютере
  для проверки без железа (пишет результат в WAV-файл)
- `docs/` — резюме проекта и бэклог задач
- [`CHANGELOG.md`](CHANGELOG.md) — история изменений по стори
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — процесс работы: бэклог, коммиты, сборка

## Разработка

На этапе PoC часть работы делается на компьютере (`sound-engine`, без
звука в Wokwi это единственный способ его услышать), часть — в Wokwi
(`firmware`, симуляция платы и MIDI-ввода без настоящего MPK), часть —
только на реальном железе (приём USB-MIDI от MPK, вывод через кодек).
