# DAWless сэмплер-секвенсор на ESP32-S3

Автономная коробка для живой игры в духе OP-1: сэмплер, многодорожечный
лупер-секвенсор и цепочка эффектов. Управление с Akai MPK mini, без
компьютера. Пет-проект для портфолио.

## Статус

Сейчас в разработке **Proof of Concept** — минимальный набор функций,
подтверждающий, что идея работает:

- 4 фиксированные дорожки, сетка 16 шагов, длина лупа 1 такт
- Ручная установка темпа, метроном, старт/стоп
- Живая запись нот с MPK mini с привязкой к шагу
- Один WAV-сэмпл на дорожку, воспроизведение с разной высотой по клавишам
- Без эффектов, без автоматизации — чистый звук

Прогресс по прошивке на сегодня:

- Готов общий интерфейс источника ввода (`InputSource`) и его реализация для
  Wokwi (`WokwiInputSource`) — пэды, клавиши и 8 крутилок читаются через
  сдвиговые регистры и ADC виртуального контроллера.
- Экран переведён в альбомную ориентацию 320×240 и подтверждён визуально в
  Wokwi. Экраны включения и приветствия работают штатно, экран загрузки
  переработан под глитч-анимацию логотипа из Claude Design (управляется
  реальным прогрессом прошивки, не видео) — см.
  [`docs/boot-screen-brief.md`](docs/boot-screen-brief.md).
- Главный экран: разделы проекта 1–4, BPM (крутилка K1), метроном, индикатор
  уровня мастер-шины, меню по MODE.
- Раздел 1 — степ-секвенсор: 4 канала (KICK/SNARE/HAT/PERC) × 16 шагов
  восьмыми, рисование паттерна пэдами, PLAY/STOP с анимацией бегущего шага.
- Звуковой движок с мастер-шиной и ваншотами по умолчанию; в Wokwi звучит
  через пищалку (грубо, 1 бит).
- **Экспорт паттерна в WAV** (44,1 кГц) для прослушивания на компьютере:
  MODE → EXPORT → PAD5, файл забирает закладка из
  [`tools/export_bookmarklet.html`](tools/export_bookmarklet.html) —
  инструкция на самой странице.
- Известные проблемы и ограничения Wokwi — в
  [`docs/known-issues.md`](docs/known-issues.md).

Полный список задуманных возможностей и порядок разработки — в
[`docs/backlog.md`](docs/backlog.md). Раскладка Akai MPK mini (клавиши, пэды,
крутилки, джойстик) — в [`docs/mpk-mapping.md`](docs/mpk-mapping.md).

## Симуляция

Прошивка (`firmware/`) собирается под ESP32-S3 и симулируется в
[Wokwi](https://wokwi.com) — там же виртуальный контроллер (пэды, клавиши,
крутилки, кнопка питания) заменяет настоящий MPK mini и кодек, пока нет
железа.

Текущий проект в Wokwi (синхронизируется с этим репозиторием вручную, не
автоматически):
[wokwi.com/projects/475304919575815169](https://wokwi.com/projects/475304919575815169)

## Железо

- ESP32-S3, вариант N16R8 (16 МБ флеш, 8 МБ PSRAM)
- Аудиокодек с одновременным входом и выходом (WM8960 или ES8388)
- microSD
- Цветной экран (ILI9341, 240×320)
- Akai MPK mini по USB

## Структура репозитория

- `firmware/` — код для ESP32-S3 (Arduino), симулируется в
  [Wokwi](https://wokwi.com)
- `sound-engine/` — звуковой движок, отдельно собирается на компьютере
  для проверки без железа (пишет результат в WAV-файл)
- `docs/` — резюме проекта, бэклог задач и известные проблемы
- `tools/` — разовые dev-инструменты для ПК (например, снятие реальной
  MIDI-раскладки с контроллера), не часть прошивки или звукового движка
- [`CHANGELOG.md`](CHANGELOG.md) — история изменений по стори
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — процесс работы: бэклог, коммиты, сборка

## Разработка

На этапе PoC часть работы делается на компьютере (`sound-engine`, без
звука в Wokwi это единственный способ его услышать), часть — в Wokwi
(`firmware`, симуляция платы и MIDI-ввода без настоящего MPK), часть —
только на реальном железе (приём USB-MIDI от MPK, вывод через кодек).
